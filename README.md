# Cresto Digital Homepage

A responsive static homepage ready for GitHub Pages.

## Publish

1. Create or open the repository `crestodigital.github.io` under the `crestodigital` GitHub account.
2. Upload all files and folders from this project to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, `main`, `/ (root)`.
4. Visit `https://crestodigital.github.io/` after deployment completes.

## Update contact email

Open `assets/js/script.js` and replace:

```js
contactEmail: "hello@crestodigital.com"
```

Also update the visible email fallback in `index.html` if needed.
